# Visual Micro: projektbezogene Build-Einstellungen (ueberschreiben die ESP32-Plattform nur fuer uhr4).
# Visual Micro: project-specific build settings (override the ESP32 platform for uhr4 only).
#
# -mtext-section-literals: Literale direkt neben jede Funktion legen. uhr4 ist eine einzige, grosse
# Uebersetzungseinheit - ohne den Schalter liegen Funktion und Literal irgendwann mehr als 256 KB auseinander
# und der Linker meldet "dangerous relocation: l32r: literal target out of range".
# -mtext-section-literals: place literals right next to each function. uhr4 is one single, large
# translation unit - without the switch, function and literal eventually lie more than 256 KB apart and the
# linker reports "dangerous relocation: l32r: literal target out of range".
#
# Arduino IDE / arduino-cli lesen diese Datei nicht: dort die platform.local.txt aus dem Projektordner neben
# die platform.txt des ESP32-Cores kopieren (Pfade siehe dort) oder --build-property verwenden.
# Arduino IDE / arduino-cli don't read this file: there, copy platform.local.txt from the project folder
# next to the ESP32 core's platform.txt (paths see there), or use --build-property.

# Nur der ESP32-S2 (Xtensa) kennt den Schalter, der ESP32-C6 (RISC-V) bricht damit ab - {build.mcu} waehlt
# den passenden Eintrag (wie build.extra_flags.<mcu> in der platform.txt des Cores).
# Only the ESP32-S2 (Xtensa) knows the switch, the ESP32-C6 (RISC-V) aborts with it - {build.mcu} picks the
# matching entry (like build.extra_flags.<mcu> in the core's platform.txt).

compiler.cpp.extra_flags={uhr4.cpp_flags.{build.mcu}}
uhr4.cpp_flags.esp32s2=-mtext-section-literals
uhr4.cpp_flags.esp32c6=
